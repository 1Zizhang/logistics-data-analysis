# 商品配送与用户反馈数据分析项目

## 1.项目简介

​	本项目基于某企业6种商品的送货配送数据与用户反馈数据，使用Python开展探索性数据分析。从配送服务质量、区域销售潜力、商品质量问题三个方向进行挖掘，定位当前业务痛点，输出物流优化、市场投放以及产品质检方面的决策建议。

## 2.技术栈

- Python-Pandas：数据清洗、指标统计、透视分析
- Numpy：数据运算
- Matplotlib：可视化图表绘制

## 4.需求分析结论

### 4.1.配送服务是否存在问题维度分析

#### 4.1.1.按时交货率维度分析

通过按时交货率看，Q4季度比Q3季度低，猜测可能由于季节更替原因（气候原因导致）

#### 4.1.2.销售区域维度分析

西北地区存在明显的延时交货情况，需要进行解决！

#### 4.1.3.货品维度分析

货品4晚交货情况较为严重，其余货品按时交货率相对正常

#### 4.1.4.货品+销售区域维度分析

销售区域：西北地区较差，货品配送主要为1和4，其中按时交货率低主要由于货品4晚交货导致！

货品：：货品2主要运往华东和马来西亚，主要为马来西亚晚交货导致！

### 4.2.是否存在尚有潜力的销售区域

1.**时间维度**：货品2销量爆发期集中在每年10‑12月份，销量增长来源于华东地区，增量大概率来自营销活动拉动；其余月份该区域销量偏低，存在营销提升空间。

2.**货品‑区域覆盖现状**：各货品市场覆盖不均衡，货品1覆盖3个销售区域，货品2覆盖2个区域，剩余货品仅投放单个销售区域，部分货品市场拓展潜力较大。

3.**优化建议**：华东地区是货品2核心增量市场，可以在非旺季月份加大营销投入，拉动淡季销量。

### 4.3货品质量风险评估（拒货率、返修率、合格率）

1.货品3、货品5、货品6质量表现优异：合格率高、返修与拒货事件较少。

2.货品1、货品2、货品4质量风险偏高：返修率、拒货率偏高，生产端质量有待优化。

3.货品2在马来西亚区域拒货率最高；结合交付数据判断马来西亚客户对于配送时效敏感度高，延迟交货容易引发拒收。

### 4.4.业务优化建议🚚配送优化方向

1.针对西北地区、货品4建立专项物流跟进方案，优化该线路的配送调度。

2.马来西亚区域的货品2订单优先保障发货时效，降低因延期交货带来的拒收风险。

3.每年第四季度提前做好物流运力储备，抵消季节性带来的交货率下滑。

4.📈市场投放方向

1. 深耕华东地区货品2市场，淡季增加营销投放，平滑全年销量。
2. 对于仅单一区域销售的货品，可开展市场调研，评估拓展新销售区域的可行性。

5.🔧货品质量管理方向

	1. 货品1、2、4启动质量复盘，排查生产环节问题，降低返修与拒收率。
	1. 货品3、5、6作为优质产品线，可作为后续市场拓展主推货品。
